# GOTCHAS.md — Ponte

Traps that already bit this project. Read before editing. When one becomes a general rule it moves to AGENTS.md.

- **Fictitious data only in public**: real contact names were replaced before opening the repo; the real-history archive lives in a separate private repo — keep it that way.
- **In-app browsers differ**: WhatsApp's in-app browser broke expectations once; the README carries a one-line notice. Test share/open flows inside in-app browsers, not only desktop Chrome.
- **Close (X) behaviour**: the X button flow was a fixed bug — keep it consistent when touching navigation.
